# 🌀 CC_Lambda

A lightweight serverless system to deploy and run user-defined functions in isolated environments (Docker/gVisor), with metrics and frontend management.

---

## 📦 Tech Stack
- **Backend**: FastAPI (Python)
- **Containerization**: Docker, gVisor (optional)
- **Frontend**: Streamlit or React (optional)
- **CI/CD**: GitHub Actions
